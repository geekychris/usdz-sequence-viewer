USDZ Sequence Viewer

3D model viewer with a scripting engine for sequencing scenes.

⬇ Download tutorial (MP4) 📖 Full User Guide ← Repository on GitHub

What this is

A small tool for building narrated 3D presentations from .glb / .usdz models. Arrange models into scenes, script rotations, translations, and scale animations, add text overlays with fades, wire in audio, and record the whole thing to WebM or MP4.

Getting started

Clone the repo and run ./serve.sh for the web version, or npm install && npm start for the self-contained Electron desktop app. Full instructions in the README quick-start.

Built with three.js, Electron, Playwright, and Kokoro TTS.
